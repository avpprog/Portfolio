Publishing to GitHub Pages

  1. Create Repository: Go to GitHub and create a new public repository named username.github.io or portfolio.
  2. Save File: Save this complete code as index.html in your project folder.
  3. Push to GitHub:
    git init
    git add index.html
    git commit -m "Initial portfolio commit"
    git branch -M main
    git remote add origin https://github.com/your-user/your-repo.git
    git push -u origin main
  4. Enable Pages: Navigate to Settings -> Pages on GitHub. Set Source branch to main and folder to / (root). Click Save!
